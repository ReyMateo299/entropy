The Critical Conceptual Difference

Cross Entropy H(P, Q) evaluates ONE random variable under two different distribution models: how expensive it is to describe events sampled from P using code tuned to Q.

Joint Entropy H(X, Y) evaluates TWO simultaneous random variables: the total net uncertainty present when observing both (X, Y) together.

Panel 1: Cross Entropy H(P, Q)

Expected code-length when encoding events from true distribution P using code optimized for Q.

H(P, Q) = H(P) + DKL(P || Q)
Composition of H(P, Q): H(P) = 1.42 nats + D_KL(P||Q) = 0.52 nats
Base Uncertainty H(P) Mismatch Penalty DKL(P || Q) ≥ 0
Analytical Gaussian Formula:
$$H(P, Q) = \frac{1}{2}\ln(2\pi\sigma_q^2) + \frac{\sigma_p^2 + (\mu_p - \mu_q)^2}{2\sigma_q^2}$$
Asymmetry Note: If σq is much smaller than σp, H(P, Q) explodes severely because Q allocates virtually zero probability to regions where P still produces samples. Thus H(P, Q) ≠ H(Q, P).

Panel 2: Joint Entropy H(X, Y)

Total uncertainty of the combined bivariate distribution (X, Y) with covariance matrix Σ.

H(X, Y) = H(X) + H(Y) - I(X; Y)
X ~ 𝒩(μp, σp2) Y ~ 𝒩(μq, σq2)
Uncertainty Contraction

When correlation ρ → ±1, knowing X almost completely determines Y. The distribution squashes into a line, driving joint differential entropy toward -∞.

H(X) + H(Y): 2.84 nats
Mutual Info I(X;Y): -0.14 nats
Joint H(X, Y): 2.70 nats
Differential Joint Entropy:
$$H(X, Y) = 1 + \ln(2\pi\sigma_p\sigma_q\sqrt{1-\rho^2})$$
Determinant of Σ = σp2σq2(1 - ρ2).
